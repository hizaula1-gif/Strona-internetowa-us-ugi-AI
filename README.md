# Projekt: Czy AI poleca Twoją markę?

Prosta strona internetowa przedstawiająca ofertę monitoringu widoczności marek w sztucznej inteligencji.

## Struktura plików
- `index.html` – główna struktura strony i treść
- `style.css` – wygląd, style 
- `script.js` – skrypty odpowiedzialne za dynamiczne ustawianie roku, płynne działanie oraz walidację formularza kontaktowego

## Sposób uruchomienia
1. Pobierz lub skopiuj wszystkie trzy pliki (`index.html`, `style.css`, `script.js`) do tego samego folderu na dysku.
2. Kliknij dwukrotnie plik `index.html`, aby otworzyć go w dowolnej przeglądarce internetowej (strona działa w pełni lokalnie bez potrzeby instalowania serwera).
